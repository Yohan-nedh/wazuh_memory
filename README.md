# Système intelligent de gestion de menaces avec WAZUH, MISP et SHUFFLE

Dans ce projet, je décrirai les différentes étapes suivies pour la mise en place de ce système. Nous commencerons par l'installation de la VM GCP et des outils, puis la configuration des outils, et enfin les tests. Par la suite, nous aborderons l'installation et la configuration de nouveaux outils.
